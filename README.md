# Abdullah Global Trade (AGT) — B2B Corporate Sourcing Platform

> **"FROM VISION TO VALUE"**  
> *Connecting Business | Building Partnerships | Delivering Growth*

An interactive B2B promotional merchandise and corporate gifting catalog tailored for Pharmaceutical Product Management Departments (PMDs), institutional buyers, and brand managers across Bangladesh.

---

## 🌟 Key Features

- **Zero-Gravity GSAP Physics:** Seamless floating animation physics with dynamic reactive ground shadows for transparent WebP product assets.
- **Smart Categorization & Instant Search:** Real-time multi-category filtering (Drinkware, Lighting, Appliances, Tools, etc.) with instant keyword search.
- **Interactive Product Detail Modal:** High-resolution spec showcase, category-tailored highlights, custom branding options (Laser engraving, UV print), and instant Quote/WhatsApp triggers.
- **Digital Business Card with QR:** Flip-able AGT corporate visiting card with embedded high-error-tolerance QR code, vCard download, and native Web Share.
- **QR Scan Analytics:** Built-in visitor engagement tracker logging scans, devices, and 7-day velocity without exposing sensitive client data.
- **Mobile-First Responsive UX:** Toggleable 1-column / 2-column view tailored for mobile PMD buyers.
- **Hardened Production Security:** Pre-configured with HSTS, X-Frame-Options, Content-Type sniffing protection, Referrer policies, and sanitized inputs.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router)
- **UI & Styling:** React 19, Tailwind CSS (Custom Luxury Ivory-Cream & Navy-Gold Palette)
- **Animation:** GSAP (GreenSock Animation Platform)
- **Icons:** Lucide React
- **Asset Processing:** Sharp, BRIA AI RMBG-1.4

## 🚀 How to Deploy on Vercel

### Option 1: Import via Vercel Dashboard (Recommended)
1. Go to [vercel.com](https://vercel.com) and log in with your account.
2. Click **"Add New..."** → **"Project"**.
3. Select your GitHub repository: `TalhaTamim45/agt-platform`.
4. Keep the default settings:
   - **Framework Preset:** Next.js
   - **Root Directory:** `./`
   - **Build Command:** `npm run build`
   - **Output Directory:** `.next`
5. Click **"Deploy"** — your live website will be ready in under 1 minute!
